# IT Service Desk Analytics & Operational Insights

## Exploratory Data Analysis of Enterprise Service Desk Performance Using Microsoft Excel and SQL Server

## Project Overview

IT Service Desk Analytics & Operational Insights is a portfolio-based exploratory data analysis project investigating the operational performance of a fictional enterprise IT service desk.

The project uses Microsoft Excel as the primary exploratory analysis environment and SQL Server as a substantial relational analysis and validation environment.

The analysis is designed to investigate service demand, resolution performance, SLA performance, support-team workload, ticket characteristics, and operational patterns before translating the findings into evidence-based business insights and recommendations.

## Business Problem

Enterprise Technology Solutions (ETS) possesses service-desk operational data and basic reporting, but IT leadership lacks sufficient insight into the factors associated with service-desk workload, resolution performance, and SLA breaches.

Existing reporting provides operational counts and status information but does not sufficiently explain patterns, contributing factors, relationships, or areas that may warrant management attention.

## Primary Business Question

> What operational factors are most strongly associated with service-desk workload, long resolution times, and SLA breaches, and where should IT leadership prioritize improvement efforts?

## Analytical Approach

The project follows an end-to-end exploratory analysis process:

**Business Problem → Business Questions → Data Understanding → Data Quality → Cleaning → Exploration → Investigation → Validation → Business Insights → Recommendations**

Excel serves as the primary environment for exploratory analysis, while SQL is used substantially for relational analysis, data investigation, aggregation, and validation.

## Data Disclosure

This project uses a fictional enterprise named **Enterprise Technology Solutions (ETS)**.

The service-desk dataset will be synthetically generated for educational and portfolio purposes. It will not contain proprietary, confidential, or production data from an actual organization.

Analytical findings will therefore represent the synthetic project environment and will not be presented as findings about a real enterprise.
